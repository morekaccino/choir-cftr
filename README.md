# CHOIR: Channel Count, State Occupancy and Rates from Multichannel CFTR Recordings

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23383422.svg)](https://doi.org/10.5281/zenodo.23383422)

Code accompanying the paper *"CHOIR: Channel Count, State Occupancy and Rates from
Multichannel CFTR Recordings"* by Mohammadreza Kazemi and Andrew Eckford (York University).

CHOIR reads the summed patch-clamp current of $N$ independently gating CFTR channels and
returns the channel count $N$, the number of channels in each of the seven gating states at
every sample, and the transition rates the signal can identify. Three neural heads propose
$N$, a noise scale and a 12-rate table; an exact, differentiable hidden Markov model over
occupancy-count states scores the trace with learned Gaussian-mixture emissions. The same
likelihood trains the heads and, at test time, selects $N$ by evidence and refines the rates
by gradient ascent.

In the code the method is the **KI-HMM** track (final model `kihmm_v4_v5a`).

> All results in the paper come from a **synthetic** benchmark. No experimental recordings
> are included or required to reproduce the paper.

## Layout

```
source/                7-state CFTR kinetic model + multichannel current summation
code/04_ml/            the CHOIR method
  benchmark.py           frozen synth_v1 generator (count targets)
  benchmark_v2.py        frozen synth_v2 generator (counts + per-state labels + rates)
  chain_index.py         precomputed occupancy-count transition tables (N = 1..5)
  kinetics.py            NumPy reference for the exact count-state chain
  torch_kinetics.py      differentiable count-state chain
  torch_emissions.py     learned mixture emission density
  torch_models.py        shared temporal encoder
  torch_models_v2.py     early model (N head)
  torch_models_v4.py     CHOIR generative model (heads + emissions + exact chain)
  train_kihmm_v2.py      training loop helpers
  train_kihmm_v4.py      train CHOIR
  infer_v5.py            test-time evidence selection of N + MAP rate refinement
  eval_kihmm_v2.py       evaluation helpers
  eval_kihmm_v4.py       evaluate a trained model
  oracle_v4.py           exact-decoder reference (true N, rates, noise)
  presentation_results.py / figures_presentation_v5.py / figures_kihmm_v4.py   paper figures
  models/                trained weights (v5a, Gaussian-noise control, GH emission init)
  results/               published metric JSONs
code/05_baselines/     Python ports of the prior methods and the comparison harness
  hmm_core.py            shared exact-HMM utilities for the ports
  sdmc_port.py  vnd_port.py  idc_port.py  moffett_port.py  deepchannel_port.py
  deepchannel_seq.py     sequence variant used in the fairness check
  noise_sweep.py  figures_noise_sweep.py   ten-point noise sweep
  build_gauss_splits.py  Gaussian-noise training splits (control)
  assumption_controls.py fairness controls
  v5_reference.py        per-trace CHOIR predictions for baseline comparisons
  compare_baselines.py   head-to-head table + figure
  BASELINES.md           provenance, licenses and every porting deviation
```

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Reproduce

```bash
# 1. regenerate the frozen synthetic benchmark and the exact-chain tables
python code/04_ml/benchmark.py     --generate     # synth_v1
python code/04_ml/benchmark_v2.py  --generate     # synth_v2
python code/04_ml/chain_index.py   --build        # N = 1..5 occupancy-count tables

# 2. train CHOIR (the released paper model is code/04_ml/models/kihmm_v4_v5a.pt)
python code/04_ml/train_kihmm_v4.py --epochs 60 --tag v5a   # see --help for all flags

# 3. test-time inference: evidence selection of N and rate refinement
python code/04_ml/infer_v5.py --model code/04_ml/models/kihmm_v4_v5a.pt \
    --splits test_x1,test_x2,test_x4

# 4. baselines and the head-to-head comparison
python code/05_baselines/sdmc_port.py --verify        # same for vnd_port / idc_port / moffett_port
python code/05_baselines/compare_baselines.py

# 5. paper figures
python code/04_ml/presentation_results.py
python code/04_ml/figures_presentation_v5.py
```

Every script accepts `--help`.

## Pretrained weights

| File | What it is |
|---|---|
| `code/04_ml/models/kihmm_v4_v5a.pt` | CHOIR trained on the benchmark (generalized hyperbolic) noise |
| `code/04_ml/models/kihmm_v4_v5gauss.pt` | CHOIR retrained on Gaussian noise (control) |
| `code/05_baselines/models/deepchannel.pt` | Deep-Channel baseline retrained on the benchmark |

## Notes

- The frozen synthetic splits (~100 MB) and the exact-chain cache are regenerated by the
  commands above and are not committed.
- The baselines are re-implementations. Their provenance, licenses and every deviation from
  the original implementations are recorded in `code/05_baselines/BASELINES.md`. Reproducing
  Deep-Channel from scratch additionally needs the upstream repository described there.
